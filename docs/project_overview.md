# Project Overview

OmniBrain is an Agentic Multi-Modal RAG Orchestrator developed as part of the Axlero Solutions Internship Program.

The system is designed to process complex documents containing text, tables, charts, and images. It uses multiple AI agents to retrieve information, perform reasoning, and generate accurate responses for user queries.

The project combines Retrieval-Augmented Generation (RAG), Multi-Agent Systems, Vector Databases, and Large Language Models to create an intelligent document understanding platform.
